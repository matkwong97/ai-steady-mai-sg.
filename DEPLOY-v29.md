# v29 homepage layout patch

This update changes only the root `index.html` from v28. No changes to D1, functions, or other files.

## Deploy via GitHub on iPhone
1. Extract this ZIP in Files.
2. Open the **main** GitHub repository `matkwong97/ai-steady-mai-sg`, branch `main`.
3. Open root `index.html`, tap the pencil (edit), replace its entire contents with the contents of the v29 `index.html` file. Commit directly to `main`.
4. Cloudflare Pages automatically builds a production deployment for `ai-steady-mai-sg`. Wait for Success.
5. Reload https://ai-steady-mai-sg.pages.dev/ and inspect the homepage.

No need to run SQL or change the existing DB binding.

Note: viewport heights vary, so the full form may still require scrolling on smaller devices.
